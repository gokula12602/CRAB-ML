# CRAB ML Research Project

## Project Title

Machine-learning prediction of carbapenem resistance in
*Acinetobacter baumannii* using whole-genome-derived genomic features.

## Research Question

Can whole-genome-derived genomic features be used to predict
carbapenem resistance in *A. baumannii* using machine-learning
approaches, while investigating the influence of bacterial
lineage/population structure?

## Research Areas

- Whole-genome sequencing
- Antimicrobial resistance
- Carbapenem resistance
- Machine learning
- Explainable AI
- Bacterial lineage/population structure
